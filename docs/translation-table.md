## 配置项说明（写入 MelonLoader Preferences）

| Key | 原文描述 | 中文描述 |
|---|---|---|
| MenuEnabled | Start with menu open | 启动时打开菜单 |
| InfinityMoney | Bypass wallet deduction on purchase | 购买时不扣钱包余额 |
| FakeMoneyUI | Fake unlimited money for UI checks | 界面假显示无限金钱（仅界面判定用） |
| SkipLogos | Skip startup logos | 跳过启动厂商 logo |
| FixSaveHang | Fix save hang (skip texture conversion wait) | 修复存档卡死（跳过贴图转换等待） |
| AutoPartsPage | Auto-open parts page for placed device | 放上设备后自动打开零件页 |
| SortPartsByNotebook | Sort the parts shop to match the notebook's part order | 零件商店按笔记本里的零件顺序排序 |
| SortBoxParts | Sort the parts box by device, then assembly order | 零件箱先按设备、再按装配顺序排序 |
| HighlightMissingParts | Highlight parts missing from the current device | 高亮当前设备缺失的零件 |
| AutoScrew | Hold Z/X to screw in/unscrew all visible screws | 按住 Z 全部拧紧 / X 全部拧松螺丝 |
| ResetTimerOnFail | Reset competition timer when a competition attempt fails | 比赛失败时重置计时 |
| InstantUltrasonic | Ultrasonic cleaner finishes instantly | 超声波清洗机立即完成 |
| AutoTool | Auto-select cleaning tool or soldering iron based on element | 按零件状态自动选清洁工具或烙铁 |
| AdBlock | Hide cross-promo ad banners on browser shop pages | 屏蔽浏览器商店页的推广横幅 |
| SnapToSocket | Hold ALT to snap a dropped part into its socket | 按住 ALT 把放下的零件吸附进插槽 |
| QuickDispose | Hold SHIFT on drop: broken->shredder, dirty->cleaner, good->parts box | 按住 SHIFT 丢零件：坏→粉碎机，脏→清洗机，好→零件箱 |
| QuickDisposeManualCleaner | Shift-drop dirty parts to the manual cleaner (brush/air) instead of the ultrasonic bath | SHIFT 丢脏件去手动清洁（刷子/吹气）而不是超声波 |
| GatherParts | Press G to gather loose parts onto the mat | 按 G 把散落的零件聚到台面上 |
| RefreshMarketplace | Press CTRL+R to refresh the device shop marketplace | 按 CTRL+R 刷新设备商店 |
| CountUltrasonicInNotebook | Parts in the ultrasonic count as on-surface in the notebook | 超声波里的零件算作已在台面（笔记本里不再标缺失） |
